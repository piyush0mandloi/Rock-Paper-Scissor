# Rock Paper Scissor

A small Rock–Paper–Scissor game project implemented in Python with a simple web UI.

## Description

This repo contains a lightweight implementation of the Rock–Paper–Scissor game. It includes a Python entrypoint and a minimal web frontend (templates and static assets) so you can run and play locally.

## Features

- Play Rock, Paper, Scissor against the computer.
- Simple browser-based UI (HTML + CSS) for quick play.

## Requirements

- Python 3.8+
- (Optional) Any dependencies listed in `requirements.txt` if present.

## Run / Usage

From the project root, run:

```bash
python a.py
```

If the script starts a web server, open a browser at:

- `http://127.0.0.1:5000` or the address printed by the script.

If the script is a direct CLI game, follow on-screen prompts.

## Project Structure

- `a.py` — Python entrypoint for running the game.
- `templates/` — HTML templates (includes `index.html`).
- `static/` — Static assets like `style.css`.

## Development

- Edit `templates/index.html` and `static/style.css` to change the UI.
- Modify `a.py` to change game logic or add new features.
